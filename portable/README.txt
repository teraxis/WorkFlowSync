WorkFlowSync — синхронізація папок із пам'яттю
=============================================

Портативна програма: інсталяція не потрібна, реєстр не чіпається.
Усе, що програмі треба (config.json, база стану state.db, журнали logs\),
лежить поруч із WorkFlowSync.exe. Папку можна переносити разом із файлами.

ЯК ПОЧАТИ
---------
1. Розпакуйте цю папку туди, де вона житиме постійно, наприклад:
   D:\Tools\WorkFlowSync    (не в «Завантаження» і не на робочий стіл)
2. Запустіть WorkFlowSync.exe
3. «Папки» → «Додати пару»:
   • Тип синхронізації:
       — Дзеркало (в один бік): нове з першої папки копіюється в другу;
         видалене в першій лишається у вас; що ви видалили, перемістили
         чи змінили в другій — назад не повертається.
       — Повна синхронізація (в обидва боки): усе, що стається в одній
         папці, стається і в іншій, включно з видаленням (у Кошик).
   • Дві папки: мережеві (\\server\share\...) або будь-які дві локальні.
   • За потреби: строк зберігання (лише для дзеркала) і виключення.
4. Кнопка ▶ у картці пари вмикає автоматичну перевірку за інтервалом
   («Налаштування» → «Інтервал перевірки»), ⏸ — ставить на паузу.
   Меню ⋯ — перевірити зараз, редагувати, видалити пару.

ЩОБ ПРАЦЮВАЛО САМО
------------------
«Налаштування» → «Автоматичний запуск» → «Запускати разом із Windows»
   • зі значком в області сповіщень — під час завантаження Windows програма
     стартує тихо, без вікна: лише значок біля годинника. Вікно відкривається
     кліком по значку; закрите вікно знову ховається в трей;
   • фоновим процесом без вікна — працює wfs.exe без інтерфейсу.
Закрите вікно не зупиняє перевірку: програма ховається в трей.

ФАЙЛИ ПОРУЧ ІЗ ПРОГРАМОЮ
------------------------
WorkFlowSync.exe      вікно програми
wfs.exe               консоль (для Планувальника і скриптів)
config.example.json   приклад налаштувань (config.json створиться сам)
config.json           ваші налаштування
state.db              пам'ять програми — що вже скопійовано
logs\                 журнали; строк зберігання задається в налаштуваннях

КОНСОЛЬ (за бажанням)
---------------------
wfs.exe sync --once            один прохід по всіх активних парах
wfs.exe sync --once --dry-run  показати, що зробила б, нічого не змінюючи
wfs.exe sync --loop            працювати постійно
wfs.exe status                 коротко про стан і останній прохід
wfs.exe config validate        перевірити config.json

ВАРТО ЗНАТИ
-----------
• Видалене програмою потрапляє в Кошик, а не знищується.
• Пара, у якої обидві папки — та сама або одна всередині іншої, не приймається.
• Для мережевої папки, де у вас лише читання, беріть режим дзеркала:
  повна синхронізація пише в обидві папки.
• Перший прохід великого дерева триває довше: програма запам'ятовує, що вже є.

Потрібен Windows 10/11 (64-біт). Права адміністратора не потрібні.
