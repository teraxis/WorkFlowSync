# Випуск WorkFlowSync v0.3.20

Портативна версія для Windows x64.

## Основні зміни

- Виправлено збій `Path shortening collision` під час підготовки плану. Скорочення враховує найдовший вкладений шлях і за потреби скорочує батьківські теки. Нові імена зберігають щонайменше вісім символів хешу, а при збігу отримують довший хеш.
- Окремий шлях, який неможливо безпечно відобразити, показується як конфлікт плану. Інші безпечні дії лишаються доступними. Журнал містить самоперевірку цільових шляхів і деталі конфліктів.
- План може використати наявні копії зі старими хешами за структурою шляху, префіксом імені, розміром і часом зміни. Неоднозначні копії залишаються недоторканими; однакові зайві копії перед перенесенням до Кошика перевіряються повторно.
- Скрипт збірки релізу тепер завершується помилкою, якщо не вдалося зібрати GUI або CLI.

## Використання

У меню завдання відкрийте «Усунення проблем синхронізації», виберіть «Виправити довгі шляхи в цілі» та перегляньте план. Складання плану не змінює файлів. Перед виконанням звірте кількість перейменувань, копій для Кошика та конфліктів. Якщо OneDrive ще обробляє попередні зміни, дочекайтеся його завершення.

## Оновлення

Архів містить `WorkFlowSync.exe` і `wfs.exe` версії 0.3.20. Налаштування, база стану й журнал зберігаються. Поведінку переміщення хмарних заглушок у реальній парі слід підтвердити на попередньому перегляді та після виконання.
