## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.0** — це масштабне оновлення WorkFlowSync, яке приносить повноцінну інтеграцію з **Google Drive**, новий розділ **«Облікові записи»** з офіційними фірмовими логотипами провайдерів, інтерактивний браузерний візард підключення **OAuth 2.0 Loopback**, експорт та зворотну синхронізацію конвертованих веб-документів Google Docs, а також виділений блок **«Хмарні сховища»** в інтерфейсі налаштувань.

### 🌟 Що нового

#### 1. Повноцінна підтримка Google Диск (Google Drive for desktop)
- **Автоматичне виявлення віртуального диска:** програма автоматично розпізнає змонтований диск Google Диска з фірмовою хмарною піктограмою та підписом у списку завдань.
- **Хмарний браузер папок:** кнопка з хмарною піктограмою у вікні налаштування завдання відкриває модальне вікно огляду структури папок вашого Google Диска з можливістю обрати як окрему підпапку, так і весь диск цілком.
- **Автоматична конвертація Google Docs:** нативні веб-документи (`.gdoc`, `.gsheet`, `.gslides`, `.gdraw`), які за замовчуванням є безтілесними системними посиланнями, автоматично конвертуються через Google Drive API в офісні формати (`.docx`, `.xlsx`, `.pptx`, `.png`) або PDF.
- **Гарантія безпеки джерела:** конвертовані файли записуються виключно в папку призначення; оригінал на Google Диску захищений від видалення чи затирання.
- **Зворотна синхронізація (`UploadConvertedDocs`):** прапорець у налаштуваннях завдання дозволяє у режимі двобічної синхронізації автоматично вивантажувати локально відредаговані файли (`.docx`, `.xlsx`) назад на Google Диск як повноцінні файли.

#### 2. Новий розділ «Облікові записи» та інтерактивний візард
- **Централізоване керування хмарами:** додано розділ «Облікові записи» у головну навігаційну панель програми.
- **Каталог провайдерів:** вибір хмарного сховища (Google Drive, Microsoft OneDrive, Dropbox, Nextcloud, AWS S3, SFTP) з офіційними фірмовими векторними логотипами та бейджами доступності.
- **Інтерактивна карусель Google Cloud Console:** покрокова 5-етапна інструкція з навігацією «Назад» / «Далі», прямими посиланнями на сторінки консолі та круглими індикаторами-точками поточного кроку.
- **Авторизація OAuth 2.0 Loopback (RFC 8252):** підключення в браузері в один клік без ручного копіювання токенів, перевірка статусу підключення та автоматичне оновлення токенів доступу.

#### 3. Виділений блок «Хмарні сховища» в інтерфейсі
- **У вікні завдання (`PairDialog`):** усі параметри для хмарних сховищ винесено в окрему картку:
  - *«Файли у хмарі»* — вибір режиму роботи з Windows Files On-Demand (OneDrive / Google Drive).
  - *«Вивільнення місця»* — автоматичне повернення скопійованих файлів у стан «лише онлайн».
  - *«Документи Google»* — вибір формату експорту веб-документів (офісні формати, PDF або пропуск).
  - *«Синхронізувати конвертовані файли»* — чекбокс вивантаження локальних правок у хмару.
- **У загальних налаштуваннях (`Settings`):** блок «ХМАРНІ СХОВИЩА» із підсумком підключених хмарних акаунтів та кнопкою швидкого переходу до керування обліковими записами.

#### 4. Двомовна документація
- Репозиторій повністю оновлено для міжнародної спільноти: додано двомовну документацію (`README.md` та `README.en.md`).

## 🇬🇧 Release Notes (English)

Version **v0.3.0** is a major update to WorkFlowSync that introduces native **Google Drive** integration, a brand-new **"Accounts"** section featuring authentic provider vector logos, an interactive **OAuth 2.0 Loopback** browser sign-in wizard, automatic export & reverse synchronization of Google Docs, and dedicated **"Cloud Storage"** setting cards.

### 🌟 What's New

#### 1. Full Google Drive for desktop Integration
- **Automatic Drive Detection:** Mounted Google Drive virtual disks are auto-detected, accompanied by cloud badges and friendly disk names.
- **Remote Folder Browser:** Click the cloud icon in task configuration to navigate your remote Google Drive tree and pick any subfolder or the entire drive.
- **Google Docs & Sheets Export:** Web-native Google Docs (`.gdoc`, `.gsheet`, `.gslides`, `.gdraw`) are automatically converted via the Google Drive API into standard Office formats (`.docx`, `.xlsx`, `.pptx`, `.png`) or PDF.
- **Source-Safe Guarantee:** Converted files are destination-only; original cloud documents are never modified or deleted.
- **Reverse Sync (`UploadConvertedDocs`):** When enabled in two-way mode, locally edited Office files are uploaded back to Google Drive as standard files.

#### 2. Brand-New "Accounts" Section & OAuth Wizard
- **Centralized Cloud Hub:** New dedicated navigation item for connecting and monitoring cloud service accounts.
- **Provider Grid:** Seamless cards with official vector logos for Google Drive, OneDrive, Dropbox, Nextcloud, AWS S3, and SFTP.
- **Google Cloud Console Carousel:** Clean 5-step tutorial with circular progress indicators, direct links to developer console pages, and full-bleed layout.
- **1-Click OAuth 2.0 Loopback Sign-In (RFC 8252):** Effortless browser sign-in without manual token copy-pasting, live connectivity tests, and automatic token refresh.

#### 3. Dedicated "Cloud Storage" Settings Blocks
- **Task Dialog (`PairDialog`):** All cloud-related controls gathered into a dedicated card:
  - *Cloud Files* (Windows Files On-Demand behavior).
  - *Free Up Space* (online-only offloading).
  - *Google Documents* (export mode selection).
  - *Synchronize Converted Files* (reverse sync toggle).
- **Settings Page:** Status card summarizing connected cloud accounts with a 1-click shortcut to the Accounts management page.

#### 4. Bilingual Repository Documentation
- Full English and Ukrainian documentation parity on GitHub (`README.md` and `README.en.md`).
