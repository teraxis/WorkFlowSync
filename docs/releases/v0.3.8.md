## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.8** усуває проблему відображення застарілого статусу «Помилка» на картках завдань у графічному інтерфейсі після успішного повторного або ручного проходу.

### 🌟 Виправлення

- **Оновлення стану помилки в картках завдань:** якщо попередній прохід синхронізації завершився зі збоєм (наприклад, через тимчасову зупинку провайдера OneDrive чи мережевої папки), а наступний ручний або фоновий запуск пройшов без помилок, інтерфейс тепер негайно оновлює та очищує лічильник помилок у пам'яті програми. Картка завдання миттєво переходить у статус «Актуально» (зелений індикатор), а попередження в статус-рядку зникає.
- **Синхронізація подій запуску:** забезпечено наскрізну передачу результатів ручного виконання завдань до головної моделі вікна для синхронного оновлення карток завдань, часу та лічильників файлів.

## 🇬🇧 Release Notes (English)

Version **v0.3.8** addresses an issue where task cards in the GUI could retain a stale "Error" badge even after a subsequent manual or scheduled run succeeded with 0 errors.

### 🌟 Fixes

- **Error Badge Clearing on Successful Run:** When a sync pass encounters an error (such as a temporary cloud file provider hiccup) and a subsequent manual or automated run completes successfully with 0 errors, the UI now immediately resets the task's error count. The task badge transitions back to "Up to date" (green indicator), and the bottom status alert clears.
- **Pass Completion Event Hook:** Added seamless event propagation from manual runs to the main view model so that all task card counters, timestamps, and error states update in real time.
