## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.1** розширює можливості хмарної інтеграції з **Google Drive**, додаючи зручну вкладку **«Спільні документи»** у вікні огляду хмарних папок, підтримку ярликів Google Drive (shortcuts) та автоматичне розгортання цільових спільних папок.

### 🌟 Що нового

#### 1. Вкладка «Спільні документи» в оглядачі Google Drive
- **Розділення огляду на вкладки:** у вікні хмарного браузера папок (`CloudFolderPickerDialog`) додано дві вкладки:
  - 📁 **«Мій диск»** (*My Drive*) — ваші особисті папки на Google Диску;
  - 👥 **«Спільні документи»** (*Shared documents*) — папки та файли, якими з вами поділилися інші користувачі (`sharedWithMe = true`).
- **Глибока навігація по спільних ресурсах:** можливість заходити всередину будь-якої спільної папки зі збереженням історії переходів у «хлібних крихтах» (breadcrumbs), навігацією на рівень вгору та оновленням списку.
- **Захист від помилкового вибору кореня:** віртуальний корінь «Спільні документи» захищений від вибору як папки; інтерфейс автоматично підказує обрати конкретну спільну папку зі списку.

#### 2. Повна підтримка ярликів Google Drive (Shortcuts)
- **Розпізнавання ярликів:** підтримуються об'єкти `application/vnd.google-apps.shortcut`, створені у веб-інтерфейсі Google Диска («Додати ярлик на Диск»).
- **Автоматичне визначення цільової папки (`EffectiveFolderId`):** при відкритті ярлика програма автоматично зчитує `shortcutDetails.targetId` та відкриває вміст цільової розшареної папки.
- **Візуальні бейджі:** у списку папок біля ярликів відображається акуратна позначка `ярлик`.

#### 3. Покращення надійності хмарних сховищ
- Безпечна обробка статусів Windows Cloud Filter у середовищах, де файлова система не підтримує хмарні фільтри.
- Додано підтримку параметрів `supportsAllDrives` та `includeItemsFromAllDrives` для безперешкодної роботи зі спільними папками та дисками у Google Drive API v3.

## 🇬🇧 Release Notes (English)

Version **v0.3.1** expands **Google Drive** cloud integration by introducing the **"Shared documents"** tab in the remote folder picker, full support for Google Drive shortcuts, and seamless navigation inside shared folders.

### 🌟 What's New

#### 1. "Shared documents" Tab in Google Drive Browser
- **Dual-Tab Navigation:** The cloud folder picker (`CloudFolderPickerDialog`) now features two organized tabs:
  - 📁 **"My Drive"** — your personal Google Drive folders;
  - 👥 **"Shared documents"** — resources shared with you by other users (`sharedWithMe = true`).
- **Deep Hierarchical Navigation:** Open and browse inside any shared folder hierarchy with full breadcrumbs, "one level up", and refresh support.
- **Safe Root Guard:** The virtual shared collection root cannot be selected directly; the UI dynamically guides you to choose a concrete shared folder.

#### 2. Full Support for Google Drive Shortcuts
- **Shortcut Discovery:** Native handling of `application/vnd.google-apps.shortcut` folder pointers created via Google Drive's "Add shortcut to Drive".
- **Target Resolution (`EffectiveFolderId`):** Automatically resolves `shortcutDetails.targetId` to seamlessly open and select the underlying target folder.
- **Visual Badges:** Clear `shortcut` badge in the folder listing.

#### 3. Cloud Reliability Improvements
- Safe fallback for Windows Cloud Filter status in non-cloud filesystem environments.
- Enabled `supportsAllDrives` and `includeItemsFromAllDrives` parameters for Google Drive API v3 requests across shared folders.
