# Випуск WorkFlowSync v0.3.24

Портативна версія для Windows x64.

## Виправлено

- Ремонт скорочує довгі шляхи файлів, які вже є в цілі та спричиняють помилки OneDrive, навіть якщо вони не записані в базі синхронізації.
- Якщо джерело збереженої копії зникло, її можна перемістити в коротший шлях зі збереженням запису та історії в базі.
- Файли з уже короткою старою хешованою назвою не блокують ремонт лише через назву.

## Перед застосуванням

Після оновлення складіть план заново. Перевірте нові шляхи переміщення й конфлікти перед підтвердженням. Перевірка на справжніх заглушках OneDrive залишається потрібною.
