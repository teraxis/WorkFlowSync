## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.7** забезпечує повноцінну підтримку режиму двобічної синхронізації з підтвердженням змін у кінцевій теці (модерована тека B), додає інтуїтивне візуальне інформування про очікування рішень у головному вікні, а також реалізує автоматичне завантаження та конвертацію відеозаписів Google Meet (.gvid) у стандартний формат MP4.

### 🌟 Що нового

#### 1. Погодження змін у кінцевій теці (Moderated Folder Approvals)
- **Повне перехоплення змін:** у режимі двобічної синхронізації з опцією «погоджувати зміни в кінцевій теці» будь-які додані файли й папки, зміни вмісту, видалення, перейменування чи переміщення в кінцевій теці автоматично фіксуються в черзі погодження.
- **Захист джерела (Side A):** жодні зміни з кінцевої теки не переносяться автоматично до вихідної теки без явного рішення користувача.
- **Виправлено роботу планувальника:** усунено проблему, через яку раніше створені в кінцевій теці файли та папки не з'являлися у вікні схвалення та не генерували запитів на підтвердження.

#### 2. Індикація та швидкі дії в інтерфейсі (UI Banners & Badges)
- **Інформаційний банер у списку завдань:** при наявності нерозглянутих змін зверху списку завдань з'являється жовтий банер із підрахунком подій та кнопкою «Погодити зміни».
- **Статус на картці завдання:** замість звичного «Актуально» картка завдання відображає бурштиновий статус «Очікує погодження (N)» із золотистою піктограмою щита та прямою кнопкою «Погодити».
- **Системні сповіщення:** додаток сповіщає про необхідність схвалення змін через сповіщення Windows; клік по повідомленню одразу відкриває вікно погодження.

#### 3. Конвертація відеозаписів Google Meet (.gvid) у MP4
- **Автоматична конвертація:** веб-записи зустрічей Google Meet (.gvid) та проєкти Google Vids тепер завантажуються через Google Drive API та автоматично зберігаються як повноцінні відеофайли `.mp4` у локальну папку призначення.
- **Опція в налаштуваннях завдання:** додано прапорець «Конвертувати відеозаписи Google (.gvid) у формат MP4», активний за замовчуванням для завдань з Google Диском.
- **Автоматичне довантаження:** наявні пари з Google Диском автоматично довантажують раніше пропущені відеозаписи під час наступної синхронізації.

## 🇬🇧 Release Notes (English)

Version **v0.3.7** introduces robust support for two-way synchronization with approval for changes made in the target folder (moderated folder B), brings intuitive approval status banners and badges to the main window, and adds automated Google Meet video (.gvid) conversion to standard MP4 files.

### 🌟 What's New

#### 1. Moderated Folder Approvals
- **Comprehensive Change Interception:** When two-way sync is configured with the approval requirement for the target folder, any new files or folders, content edits, deletions, or moves/renames made in folder B are intercepted and held in the pending queue.
- **Source Protection:** Changes in folder B will not propagate back to source folder A without explicit user consent.
- **Planner Bug Resolved:** Fixed an issue where new items in folder B were previously bypassed without being captured into the pending approval database.

#### 2. Visual Approvals Indicators & Notifications
- **Pending Approvals Banner:** When unreviewed changes are detected, a prominent banner appears above the task list showing the count and an "Approve Changes" action button.
- **Task Card Badge:** Tasks with pending decisions display an amber status ("Awaiting approval") with a shield icon and an inline "Approve" button.
- **System Notifications:** A notification alerts the user to pending items and opens the approval dialog on click.

#### 3. Google Meet Video (.gvid) to MP4 Conversion
- **Automatic Export & Conversion:** Native Google Meet recordings (.gvid) and Google Vids stubs are exported via the Google Drive API directly into playable `.mp4` video files in the destination folder.
- **Task Setting:** Added the toggle option "Convert Google video recordings (.gvid) to MP4 format", enabled by default for Google Drive pairs.
- **Backfill for Existing Tasks:** Existing configured tasks will automatically fetch previously skipped recordings during subsequent sync passes.
