## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.6** додає зручну кнопку фільтрації списку завдань у головному вікні, що дозволяє зосередитися лише на активних завданнях, а також усуває збій синхронізації при обробці покажчиків відеозаписів зустрічей та скриптів Google Drive (.gvid, .gscript).

### 🌟 Що нового

#### 1. Фільтрація завдань у списку (Task Filtering)
- **Кнопка фільтрації завдань:** поруч із кнопкою «Додати завдання» додано компактну кнопку з піктограмою фільтра та випадаючим меню для швидкого перемикання між режимами «Усі завдання» та «Лише активні».
- **Приховування неактивних за замовчуванням:** за замовчуванням у списку відображаються лише активні завдання, що розвантажує інтерфейс від тимчасово призупинених або архівних пар.
- **Миттєве реагування:** у режимі «Лише активні» вимкнення завдання тумблером одразу приховує його зі списку. Перемкнувши фільтр на «Усі завдання», можна легко переглянути або знову активувати будь-яке приховане завдання.

#### 2. Безпечна обробка веб-покажчиків Google Drive (.gvid, .gscript)
- **Виправлено помилку копіювання («IOException: Incorrect function»):** файли записів зустрічей Google Meet (.gvid) та хмарні скрипти (.gscript), створені на змонтованому віртуальному диску Google Диск, не містять локального файлового потоку і раніше викликали системну помилку введення-виведення під час спроби прямого копіювання.
- **Автоматичний пропуск із попередженням:** тепер такі покажчики розпізнаються як віртуальні веб-посилання Google та безпечно пропускаються з інформативним попередженням у журналі, не перериваючи загальний процес синхронізації решти файлів у завданні.

## 🇬🇧 Release Notes (English)

Version **v0.3.6** introduces a task list filter button in the main window for easily hiding inactive tasks, and resolves a synchronization error when handling Google Drive video recording and script pointer stubs (.gvid, .gscript).

### 🌟 What's New

#### 1. Task List Filtering
- **Filter Button:** Added a filter button next to "+ Add Task" with a dropdown flyout to toggle between "All tasks" and "Active only".
- **Clean Default View:** Inactive tasks are hidden by default to keep the task list uncluttered.
- **Dynamic Response:** Disabling an active task while in the "Active only" mode immediately hides it from view. Switching to "All tasks" reveals all configured pairs for easy re-activation.

#### 2. Google Drive Stubs Handling (.gvid, .gscript)
- **Resolved "IOException: Incorrect function":** Video recording stubs (.gvid from Google Meet) and script files (.gscript) generated by Google Drive for desktop do not contain local binary streams and previously caused low-level I/O copy errors.
- **Safe Skip with Warning:** These web-only pointer stubs are now recognized as Google web objects and safely skipped with a clear log warning, allowing the rest of the sync run to complete without failure.
