## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.16** усуває зависання інтерфейсу («Не відповідає») під час підтвердження або повернення великих файлів (відеозаписів, образів та архівів у сотні мегабайтів) із хмарних сховищ OneDrive / Google Drive, переводить усі дискові та мережеві операції погодження у фоновий пул потоків та додає наочну індикацію прогресу виконання.

### 🛠️ Виправлено та покращено

- **Асинхронне виконання операцій погодження у фоновому потоці:** методи `ApproveAsync`, `DismissAsync` та `RevertAsync` у `ApprovalService` і цикл виконання у `ApprovalViewModel` переведено на справжнє асинхронне виконання у пулі потоків (`Task.Run`). Потокове завантаження файлів обсягом у сотні мегабайтів через мережеві драйвери Windows Files On-Demand більше не блокує потік інтерфейсу Avalonia, а вікно ніколи не переходить у системний стан `(Не відповідає)`.
- **Наочна індикація прогресу:** під час обробки змін у вікні відображається верхня та нижня анімована смуга прогресу (`ProgressBar`), а в рядку стану показується поточний крок та назва файлу, що обробляється (наприклад, `[1/3] Підтвердження: наради.mp4...`).
- **Захист від повторних натискань (`IsBusy`):** верхні пакетні кнопки дій («Підтвердити всі», «Залишити всі як є», «Повернути все»), кнопка «Оновити», прапорець «Обрати всі» та кнопки дій у рядках автоматично деактивуються під час виконання операції, запобігаючи конкурентним запитам або випадковим повторним клікам.
- **Стилізація рядка статусу:** повідомлення про перебіг обробки тепер виводяться акцентним кольором інтерфейсу, а червоний колір помилки використовується лише у разі виникнення реальних збоїв.

## 🇬🇧 Release Notes (English)

Version **v0.3.16** eliminates UI thread freezes ("Not Responding") when approving or reverting large files (such as multi-hundred-megabyte video recordings or archives) stored in cloud services like OneDrive or Google Drive, offloads all approval disk and network I/O to background thread pool threads, and adds real-time progress indicators.

### 🛠️ Fixed and Improved

- **Non-blocking Background Approval Execution:** Approval operations (`ApproveAsync`, `DismissAsync`, `RevertAsync` in `ApprovalService` and `ApprovalViewModel`) now run entirely on background thread pool threads via `Task.Run`. Streaming multi-hundred-megabyte files from Windows Files On-Demand providers no longer starves the Avalonia UI message pump, preventing Windows from marking the window as `(Not Responding)`.
- **Visual Progress Feedback:** While processing changes, the Approval window displays top and bottom indeterminate progress bars, and the status bar reports live item-by-item progress (e.g., `[1/3] Approving: recording.mp4...`).
- **Concurrent Action Protection (`IsBusy`):** Batch buttons ("Approve all", "Dismiss all", "Revert all"), refresh, select-all checkbox, and row action buttons are safely disabled while an operation is in flight.
- **Status Bar Styling:** Progress messages use accent styling, while danger styling is strictly reserved for actual errors.
