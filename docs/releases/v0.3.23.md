# Випуск WorkFlowSync v0.3.23

Портативна версія для Windows x64.

## Виправлено

- План ремонту залишає достатньо місця для довгого розширення файла в глибокій теці.
- Теки зі збереженими копіями файлів не позначаються як невідстежені лише через стару хешовану назву.

## Перед виправленням

План і CSV, створені попередньою версією, складіть заново після оновлення. Перевірте невідстежені файли та кількість копій для Кошика перед застосуванням. Реальна ціль OneDrive й хмарні заглушки не перевірялися автоматичними тестами.
