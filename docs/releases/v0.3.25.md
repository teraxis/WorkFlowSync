# Випуск WorkFlowSync v0.3.25

Портативна версія для Windows x64.

## Виправлено

- У вікні плану ремонту з’явився прапорець для переміщення дублікатів і порожніх тек до Кошика. За замовчуванням він вимкнений: скорочення довгих шляхів не прибирає дублікати автоматично.
- У консольній команді прибирання потребує явного `--recycle-duplicates`; CSV позначає пропущені дії як `skip-recycle-*`.
- Якщо канонічна копія відсутня та її перенесення не заплановане, програма показує конфлікт замість запланованого видалення «дубліката».

## Перед застосуванням

Після оновлення складіть план заново. Залиште прапорець вимкненим, якщо потрібно лише скоротити шляхи наявних файлів. Якщо план усе ще містить задовгі пропущені шляхи, позначка необхідності ремонту залишиться.
