## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.13** додає інтелектуальний механізм автоматичного скорочення задовгих шляхів файлів і папок для запобігання помилкам переповнення довжини шляху (`MAX_PATH`, `0x800700CE`) у Windows та збоям синхронізації у хмарних сховищах (OneDrive, Google Drive тощо).

### 🌟 Що нового

- **Автоматичне скорочення задовгих шляхів:** у блоці «Параметри системи» налаштувань завдання додано опцію скорочення довгих шляхів файлів і папок. Якщо розрахований повний шлях до файлу в локальній цільовій теці перевищує встановлений ліміт, алгоритм автоматично скорочує його:
  1. *Пріоритет 1 (ім'я файлу):* скорочується ім'я файлу зі збереженням оригінального розширення та додаванням детермінованого 8-символьного SHA-256 хешу (`_#xxxxxxxx`), що гарантує відсутність колізій імен.
  2. *Пріоритет 2 (папки):* якщо довжина шляху перевищує ліміт навіть після скорочення назви файлу, алгоритм пропорційно скорочує назви найдовших батьківських каталогів.
- **Пам'ять про скорочення (стабільність синхронізації):** у базі стану `state.db` зберігається зв'язок скороченого локального шляху з оригінальним відносним шляхом у джерелі (`remote_id`). Програма точно знає, яким вихідним файлам відповідають скорочені копії, не намагається повторно завантажувати їх з довгими іменами на наступних проходах, а у двобічному режимі (`twoWay`) безпечно переносить зміни до вихідних файлів на сервері.
- **Гнучке налаштування ліміту довжини:** можливість встановити власний поріг довжини шляху (`maxPathLength`, типово 240 символів, допустимий діапазон від 80 до 1000). Елемент керування винесено на окремий підрядок із логічною залежністю від активності опції.

## 🇬🇧 Release Notes (English)

Version **v0.3.13** introduces an intelligent path shortening engine designed to prevent filesystem path length limit errors (`MAX_PATH`, `0x800700CE`) in Windows and synchronization stalls in cloud clients like Microsoft OneDrive and Google Drive.

### 🌟 What's New

- **Automated Long Path Shortening:** A new setting under «System Parameters» allows automatic path shortening for local targets. When a destination file's absolute path exceeds the configured threshold, the algorithm safely trims it:
  1. *Priority 1 (File name):* Trims the file name while preserving its original file extension and appending a deterministic 8-character SHA-256 hash tag (`_#xxxxxxxx`) to prevent any collisions.
  2. *Priority 2 (Directories):* If parent directories alone cause path overflow, the longest folder segments are deterministically shortened as well.
- **Persistent Path Mapping:** Mappings between shortened destination files and original source relative paths are tracked in `state.db` via `remote_id`. The sync engine reliably recognizes previously shortened files on subsequent runs without triggering redundant re-downloads. In `twoWay` sync mode, local changes safely propagate back to the original source paths.
- **Configurable Length Threshold:** Configure your preferred maximum path limit (`maxPathLength`, default 240 characters, range 80..1000) with dedicated UI controls that gracefully adapt to the toggle state.
