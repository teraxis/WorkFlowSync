## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.10** додає розділ налаштованого очищення кінцевої теки із лімітом кількості файлів та захистом наявних даних, детальний прогрес синхронізації у статусах та виправлення графічного відображення іконки помилки.

### 🌟 Що нового

- **Розділ «Налаштоване очищення» (`CleanExistingFiles`, `KeepLatestFiles`):** у діалозі налаштування завдання виділено окремий блок «НАЛАШТОВАНЕ ОЧИЩЕННЯ».
- **Ліміт кількості файлів у кінцевій теці:** можливість утримувати у кінцевій теці тільки вказану кількість найновіших файлів. Старіші файли безпечно переміщуються до Кошика (Recycle Bin).
- **Підтвердження активації та захист існуючих файлів:** перед увімкненням політик очищення з'являється діалогове вікно підтвердження із червоною кнопкою «Увімкнути» та прапорцем «Застосувати до існуючих файлів». Якщо прапорець вимкнено, файли, що вже були у теці до моменту активації, гарантовано захищені від видалення.
- **Точний облік за часом синхронізації:** визначення віку та порядку файлів при очищенні базується виключно на часі появи/копіювання файлу в системі WorkFlowSync, а не на системних атрибутах створення (`ctime`) чи зміни (`mtime`).
- **Детальний прогрес синхронізації у статусах:** під час активної синхронізації у бейджі завдання, заголовку, підзаголовку картки та рядку активності відображається кількість синхронізованих файлів, загальна кількість та відсоток виконання `(синхронізовано X з Y (Z%))`.

### 🛠️ Виправлення

- **Іконка статусу помилки:** виправлено геометрію іконки помилки завдання (`IconDismiss`) — діагональна лінія перекреслення тепер ідеально вписується у кружечок та не виступає за його межі.

## 🇬🇧 Release Notes (English)

Version **v0.3.10** introduces a dedicated Configured Cleanup section with target file limits and existing file protection, detailed progress tracking in sync statuses, and error icon visual styling fixes.

### 🌟 What's New

- **Configured Target Cleanup (`CleanExistingFiles`, `KeepLatestFiles`):** Dedicated "CONFIGURED CLEANUP" card in the task settings dialog.
- **Keep Latest Files Limit:** Ability to retain only the specified number of newest files in the destination folder. Older files are moved safely to the Recycle Bin.
- **Confirmation Dialog & Existing Files Protection:** Enabling cleanup policies prompts a confirmation modal with an accent button and an "Apply to existing files" option. When disabled, existing files are protected from deletion, applying retention only to files synchronized after activation.
- **Strict Sync-Time Identification:** File ordering and expiration are strictly identified by WorkFlowSync appearance/copy timestamps rather than filesystem creation (`ctime`) or modification (`mtime`) dates.
- **Detailed Sync Progress Reporting:** While synchronization is in progress, the task status badge, title, subtitle, and activity bar display the current synced count, total files, and percentage `(synced X of Y (Z%))`.

### 🛠️ Fixes

- **Error Status Icon Geometry:** Corrected `IconDismiss` diagonal line bounds to stay strictly inside the circular badge border.
