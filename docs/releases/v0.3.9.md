## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.9** додає можливість автоматичного вивільнення місця у вихідній хмарній теці (OneDrive та інші сховища Windows Files On-Demand) після копіювання файлів.

### 🌟 Що нового

- **Вивільнення місця у вихідній теці (`freeUpSourceSpaceAfterCopy`):** у схемах синхронізації, де джерелом є хмарне сховище OneDrive (наприклад, «OneDrive → Google Диск» або локальний диск), читання файлів для копіювання призводить до їх автоматичного завантаження на локальний диск. Нова опція повертає скопійованим вихідним файлам статус «лише онлайн» (дегідратація / `Unpinned`), захищаючи локальний диск від заповнення кешем.
- **Збереження закріплених файлів:** файли у вихідній теці, які користувач явно закріпив як «Завжди зберігати на цьому пристрої» (`Pinned`), залишаються локальними і не розпіновуються.
- **Керування в інтерфейсі:** у діалозі налаштування завдання у блоці «ХМАРНЕ СХОВИЩЕ» додано прапорець «Вивільнення в джерелі», активний тоді, коли вихідна папка розміщена у сумісному хмарному sync root.

### 🛠️ Виправлення

- **Стійкість до недоступності цільового диску:** додано безпечну обробку відсутності або недоступності цільового диска чи теки без аварійного збою синхронізації.

## 🇬🇧 Release Notes (English)

Version **v0.3.9** introduces automatic cloud offloading for source folders within Windows Files On-Demand providers (such as OneDrive) after copying files to the destination.

### 🌟 What's New

- **Source Cloud Offloading (`freeUpSourceSpaceAfterCopy`):** In sync configurations where the source is a cloud folder (e.g. "OneDrive → Google Drive" or a local backup drive), reading placeholders downloads their bytes to the local disk. When this option is enabled, WorkFlowSync automatically requests the «online-only» state (`Unpinned`) on the source files after successful copy, freeing local disk space.
- **Preservation of Pinned Files:** Files in the source directory that have been explicitly marked by the user as "Always keep on this device" (`Pinned`) are preserved and will not be unpinned.
- **UI Setting:** Added a "Source offload" checkbox in the "CLOUD STORAGE" card of the task edit dialog, enabled whenever the source path is located inside a recognized Windows Files On-Demand sync root.

### 🛠️ Fixes

- **Target Availability Handling:** Added safe exception handling for unavailable target drives/directories, preventing sync pass crashes when target media is disconnected.
