## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.2** фокусується на зручності перегляду історії синхронізації, інформативності застосунку та візуальній уніфікації інтерфейсу. Додано динамічне підвантаження старіших записів у вікні останніх змін, новий розділ «Про програму» з інтегрованою перевіркою оновлень, уніфіковане контекстне меню керування акаунтами та компактні естетичні смуги прокручування.

### 🌟 Що нового

#### 1. Динамічне підвантаження у вікні останніх змін
- **Нескінченна прокрутка (Infinite Scroll):** тепер вікно останніх змін не обмежене фіксованою кількістю останніх файлів. При прокручуванні списку вниз автоматично підвантажуються наступні порції (по 50 файлів), дозволяючи переглянути всю історію операцій.
- **Збереження позиції скролу:** підвантаження здійснюється безшовно без скидання позиції перегляду та без блимання інтерфейсу.
- **Підтримка фільтрації:** перемикання між вкладками («Усі», «Скопійовані», «Конвертовані», «Вивантажені», «Видалені») автоматично скидає пагінацію на початок обраної категорії та динамічно довантажує записи відповідно до фільтра.

#### 2. Новий розділ «Про програму»
- **Централізована інформація:** у головній навігаційній панелі з'явився пункт «Про програму» з інформацією про версію, автора (Білик Ігор), контакти зворотного зв'язку (`teraxis@gmail.com`) та ліцензію MIT.
- **Швидкий перехід до ресурсів:** прямі посилання на офіційний GitHub-репозиторій проєкту та сторінку релізів.

#### 3. Інтегрована перевірка оновлень у розділі «Про програму»
- **Єдиний механізм оновлення:** кнопка «Перевірити оновлення» у розділі «Про програму» тепер використовує ту саму нативну логіку, що й перевірка під час запуску програми.
- **Сповіщення біля трею:** перевірка виконується у фоні через GitHub Releases API; у разі виявлення нової версії з'являється вікно біля системного трею із переліком змін та можливістю оновлення в один клік без ручного завантаження файлів.

#### 4. Уніфіковане керування обліковими записами
- **Єдиний стиль дій:** кнопку керування акаунтами у розділі «Облікові записи» приведено до єдиного дизайну з картками завдань на головному екрані — компактна кнопка дій `⋯` (36×24 px).
- **Контекстне меню:** швидкий доступ до операцій «Перевірити підключення» та «Видалити обліковий запис» із підтвердженням дії у фірмовому діалоговому вікні.

#### 5. Уніфіковані тонкі смуги прокручування (5 px) та оптимізація простору
- **Компактний скролбар:** товщину смуги прокручування в усіх розділах, картках та діалогах програми стандартизовано до 5 px (удвічі вужче попереднього розміру) із фіксованою геометрією без раптового розширення при наведенні курсора.
- **Збільшення корисної площі:** зменшено бічні відступи (ліворуч та праворуч) в усіх контейнерах програми відповідно до компактного скролу, що забезпечило більше корисного простору для карток завдань, списків і налаштувань.

#### 6. Очищення розділу «Налаштування»
- Вилучено надлишковий блок «Хмарні сховища» із загальних налаштувань — усе керування підключеними хмарами тепер повністю зосереджено у відповідному розділі «Облікові записи».

## 🇬🇧 Release Notes (English)

Version **v0.3.2** introduces dynamic history pagination for recent changes, a brand-new "About" section with native update checking, unified account actions, and streamlined slim scrollbars across the entire application.

### 🌟 What's New

#### 1. Dynamic Loading in Recent Changes
- **Infinite Scrolling:** The Recent Changes window is no longer limited to a fixed initial batch. Scrolling down automatically fetches older synchronized records in chunks of 50 items.
- **Seamless Scroll Stability:** Records are appended smoothly without scroll jumping or UI flicker.
- **Category-Aware Pagination:** Filtering tabs ("All", "Copied", "Converted", "Offloaded", "Deleted") reset and paginate cleanly per category.

#### 2. Dedicated "About" Section
- **Product & Creator Credits:** Added an "About" page to the primary navigation rail displaying product info, author credentials (Ihor Bilyk), contact email (`teraxis@gmail.com`), and MIT license details.
- **Direct Web Links:** Quick access to the GitHub project repository and release downloads.

#### 3. Integrated Native Update Checker
- **Unified Update Flow:** The "Check for Updates" button on the About page triggers the same background check as startup: queries GitHub Releases API and displays the native notification window near the system tray.
- **One-Click Installation:** Direct download, executable swap, and app restart without manual intervention.

#### 4. Unified Account Management Action Menu
- **Consistent UI Language:** Replaced the previous wide buttons in the "Accounts" section with the compact `⋯` action menu button (36×24 px), aligning with sync task cards.
- **Flyout Menu:** Quick access to "Check Connection" and "Remove Account" with confirmation dialog safety.

#### 5. Unified Slim Scrollbars (5 px) & Optimized Layout
- **Minimalist Scrollbar:** Scrollbars across all views and dialogs are unified to a sleek 5 px width with static geometry (no hover enlargement).
- **Expanded Content Space:** Adjusted left and right container paddings to maximize usable width for task cards, tables, and settings panels.

#### 6. Streamlined Settings View
- Removed redundant "Cloud Storage" summary card from general settings, centralizing all cloud account management in the dedicated "Accounts" rail page.
