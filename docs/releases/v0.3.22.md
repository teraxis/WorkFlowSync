# Випуск WorkFlowSync v0.3.22

Портативна версія для Windows x64.

## Виправлено

- План ремонту більше не позначає короткі теки верхнього рівня як конфлікт лише через глибину вкладених файлів.
- Ремонт шляхів зберігає історію видалень: `tombstone` не відновлюється автоматично. Для відновлення раніше видалених файлів використовуйте окрему дію з підтвердженням.
- Сторонні порожні теки в цілі залишаються недоторканими. Якщо план має масові помилки побудови шляхів, кнопка застосування недоступна.

## Перед виправленням

План і CSV, створені версією 0.3.21, не застосовуйте. Оновіть обидва виконувані файли, складіть новий план та перевірте кількість конфліктів, перейменувань і файлів для Кошика. Реальний OneDrive й хмарні заглушки не були перевірені автоматичними тестами.
