# Випуск WorkFlowSync v0.3.21

Портативна версія для Windows x64.

## Виправлено

- Двобічне завдання більше не показує хибний стан «Потрібне виправлення», коли для нього немає доступної дії ремонту.
- Після оновлення програма очищає застарілу позначку під час наступного проходу та знову обробляє оновлення й копіювання в обох напрямках. Наявні копії залишаються за шляхами, записаними в базі стану.

## Оновлення

Замініть `WorkFlowSync.exe` і `wfs.exe` версії 0.3.20 файлами з цього випуску. `config.json`, `state.db` і журнали зберігаються. Якщо завдання активне, наступний прохід автоматично очистить застарілу позначку. Для завдання на паузі запустіть один прохід вручну або відновіть його.
