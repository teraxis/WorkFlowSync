## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.15** усуває помилку `file in target changed again since detection` під час підтвердження змін для файлів, які кілька разів зберігалися у кінцевій теці до моменту погодження, забезпечує перенесення актуального вмісту при одночасному перейменуванні й редагуванні файлу та виправляє верстку нижньої панелі вікна «Погодження змін».

### 🛠️ Виправлено

- **Актуалізація метаданих відкритих записів `pending` при повторних збереженнях:** якщо файл, що вже очікує на погодження у `FrozenPaths`, повторно редагується та зберігається у кінцевій теці (наприклад, у Microsoft Word), фоновий прохід синхронізації, відкриття вікна «Погодження змін» (`Load()`) та дія «Підтвердити» автоматично оновлюють розмір (`DstSize`) і час модифікації (`DstMtimeUtc`) з диска. Підтвердження змін спрацьовує з першого натискання без помилки `file in target changed again since detection`.
- **Одночасне перейменування і редагування (`Renamed` / `Moved`):** під час підтвердження перейменованого або переміщеного файлу, вміст якого також було змінено в кінцевій теці, актуальна версія файлу копіюється до вихідної теки зі збереженням часу модифікації.
- **Верстка нижньої панелі вікна «Погодження змін»:** виправлено розподіл ширини колонок (`ColumnDefinitions="Auto,Auto,*"`), щоб текст підсумку (`Усього записів: N`) не стискався по вертикалі при відображенні довгих повідомлень про статус.

## 🇬🇧 Release Notes (English)

Version **v0.3.15** fixes the `file in target changed again since detection` error when approving target files that were saved multiple times after initial detection, ensures modified file contents are propagated when approving renamed/moved files, and fixes the bottom status bar layout in the Approval window.

### 🛠️ Fixed

- **Live Metadata Refresh for Frozen Pending Files:** When a file awaiting approval in `FrozenPaths` is edited and saved again in the target folder (e.g., multiple saves in Microsoft Word), background sync passes, `ApprovalViewModel.Load()`, and the `Approve` action now automatically refresh `DstSize` and `DstMtimeUtc` from disk so approval succeeds on the first click.
- **Combined Rename/Move and Edit on Approval:** Approving a `Renamed` or `Moved` file whose contents were also modified in the target folder now copies the updated target file to the new source path while preserving `LastWriteTimeUtc`.
- **Approval Window Status Bar Layout:** Fixed grid column definitions (`Auto,Auto,*`) in the bottom bar so the summary text (`Усього записів: N`) never wraps vertically when long status messages are shown.
