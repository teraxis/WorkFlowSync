## 🇺🇦 Опис релізу (Ukrainian)

Версія **v0.3.11** додає інформативне відображення загальної кількості файлів безпосередньо під шляхами вихідної (Source) та кінцевої (Target) тек у картках завдань, оптимізує збереження цих даних у базі стану та забезпечує фонове сканування локальних каталогів.

### 🌟 Що нового

- **Відображення кількості файлів під шляхами тек:** у кожній картці завдання під шляхом до вихідної та кінцевої теки тепер відображається точна загальна кількість файлів (наприклад, `87 111 файлів`, `1 файл`, `4 файли`) з повною українською плюралізацією та розбиттям розрядів.
- **Швидке відображення лічильників при запуску:** після сканування та синхронізації дані про кількість файлів зберігаються в базі даних стану (`state.db`), завдяки чому при відкритті програми лічильники з'являються миттєво без потреби повторного сканування дисків.
- **Фоновий підрахунок для локальних тек:** для локальних тек, які ще не синхронізувалися під новою версією, реалізовано автоматичний асинхронний фоновий підрахунок файлів без блокування головного інтерфейсу.
- **Точний облік активних файлів у базі даних:** метод вибірки активних файлів зі `state.db` тепер враховує лише записи файлового типу (`EntryKind.File`) та статусів активної синхронізації (`Active`, `LocalModified`, `Diverged`, `LocalOnly`).

## 🇬🇧 Release Notes (English)

Version **v0.3.11** adds file count summaries directly under source and target paths in task cards, optimizes state database persistence for instant UI loading, and provides non-blocking background scanning for local folders.

### 🌟 What's New

- **File Counts Under Source & Target Paths:** Each task card now presents the total number of files directly under the source and target path labels (e.g. `87 111 файлів`, `1 файл`, `4 файли`) with localized pluralization and number grouping.
- **Instant Count Loading on Startup:** File counts are cached in the `state.db` metadata table after each scan/sync pass, allowing the application to immediately display file totals upon opening without re-reading the filesystem.
- **Background Counter for Local Directories:** If a task has not yet been synced under the latest version, an asynchronous background scanner counts files for local directories without freezing the user interface.
- **Accurate Active File Querying in State Store:** Corrected database active file counting to strictly target `EntryKind.File` and physical target entry statuses (`Active`, `LocalModified`, `Diverged`, `LocalOnly`).
