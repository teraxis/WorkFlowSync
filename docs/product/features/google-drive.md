# Синхронізація з Google Диск

## Призначення

Підтримка синхронізації файлів та папок між локальними каталогами (або мережевими сховищами) та Google Диск (Google Drive).
Функціонал працює як у режимі одностороннього дзеркала (`Mirror`), так і у режимі повної двобічної синхронізації (`TwoWay`).

## Архітектура інтеграції

Інтеграція реалізована у два етапи:

### Фаза 1: Google Drive for desktop (поточна реалізація)

Офіційний клієнт **Google Drive for desktop** монтує хмарне сховище як віртуальний том Windows (за замовчуванням диск `G:\` з міткою тому `Google Drive` та типом файлової системи `Google DriveFS` або `FAT32`), або синхронізує обрані каталоги як дзеркальні папки на локальних дисках.

1. **Автоматичне розпізнавання сховища:**
   - Модуль `WorkFlowSync.Core.GoogleDrive` перевіряє доступні дискові томи і визначає змонтований Google Диск (`VolumeLabel == "Google Drive"` або формат `Google DriveFS`).
   - При виборі папки на диску або шляху всередині каталогу `Google Drive` інтерфейс програми автоматично присвоює типу сховища статус **«Google Диск»** та відображає відповідну хмарну піктограму.
2. **Вибір папки через стандартний «Огляд…»:**
   - Папки на Google Диску обираються через стандартну системну кнопку **«Огляд…»** (диск `G:\` доступний у лівій навігаційній панелі провідника) або ручним введенням шляху. Це зберігає єдиний, чистий інтерфейс без зайвих специфічних кнопок.
3. **Режими синхронізації:**
   - **Дзеркало (`Mirror`):** Локальна або мережева папка копіюється на Google Диск (або навпаки), при цьому джерело залишається незмінним.
   - **Двобічна синхронізація (`TwoWay`):** Додавання, редагування та видалення файлів поширюються в обидва боки з веденням бази стану `state.db`, перевіркою версій та безпечним переміщенням до Кошика.

### Конвертація та завантаження веб-документів Google (.gdoc, .gsheet, .gslides тощо)

У віртуальній файловій системі Google Drive for desktop документи, створені безпосередньо у веб-інтерфейсі Google Docs/Sheets/Slides, не є звичайними бінарними файлами — це віртуальні покажчики (stubs). Спроба їх прямого побайтового копіювання викликає помилку операційної системи Windows.

#### Реалізований функціонал:
WorkFlowSync автоматично конвертує та завантажує веб-документи Google у повноцінні файли за такими правилами:

1. **Режими конвертації (налаштовується для кожної пари):**
   - **Офісні формати (`Office`, за замовчуванням):**
     - `.gdoc` → `.docx` (Microsoft Word)
     - `.gsheet` → `.xlsx` (Microsoft Excel)
     - `.gslides` → `.pptx` (Microsoft PowerPoint)
     - `.gdraw` → `.png` (Зображення PNG)
   - **PDF (`Pdf`):** усі підтримувані документи експортуються у формат `.pdf`.
   - **Пропускати (`Skip`):** веб-документи ігноруються, як у попередній версії.
   - Спеціальні типи без бінарного експорту (`.gform`, `.gsite`, `.gshortcut`) безпечно пропускаються.

2. **Суворе правило «Лише в папку призначення» (Destination-only):**
   - Конвертовані файли завантажуються **виключно в папку призначення** (з Google Диска на локальний диск або інше цільове сховище).
   - **Заборона зворотного перезапису:** у режимі `TwoWay` змінений локальний `.docx` або `.xlsx` **ніколи** не передається назад у Google Диск і не намагається перезаписати хмарний `.gdoc`. Це гарантує збереження хмарного оригіналу.
   - **Захист від видалення оригіналу:** якщо користувач видаляє експортований `.docx` у локальній папці, планувальник `TwoWayPlanner` не видаляє відповідний `.gdoc` на Google Диску, а виводить інформаційне повідомлення в лог.

3. **Автоматичне визначення Google Drive File ID:**
   - Для завантаження експортованого вмісту модуль `GoogleDrive` зчитує локальну базу метаданих Google Drive for desktop (`metadata_sqlite_db` у каталозі `%LOCALAPPDATA%\Google\DriveFS\<account_id>\`) у режимі `ReadOnly`.
   - Завдяки цьому визначення ID документа відбувається миттєво без додаткових мережевих запитів. Якщо база недоступна, ID витягується з локального JSON-файлу покажчика.

4. **Завантаження через Google Drive REST API:**
   - Компонент `GoogleDriveExporter` виконує експорт через офіційний API Google Drive (`https://www.googleapis.com/drive/v3/files/{fileId}/export?mimeType=...`).
   - Завантаження виконується атомарно (через тимчасовий файл `.tmp`) зі збереженням точного часу модифікації документа (`mtime`).
   - Якщо токен авторизації не налаштовано, програма виводить попередження в журнал і акуратно пропускає експорт документа без збою синхронізації інших файлів.

5. **Інтерфейс користувача:**
   - У вікні редагування пари папок (`PairDialog`) у розділі «Правила синхронізації» додано вибір: **«Експорт документів Google»** із вибором між *Офісні формати (за замовчуванням)*, *PDF* та *Пропускати*.
   - Інформація про обраний режим експорту також відображається у блоці характеристик пари («Характеристики»).

### Налаштування авторизації Google API (GoogleAuth)

Для використання експорту через Google Drive REST API у конфігурації `config.json` передбачено секцію `google_auth`:
```json
{
  "google_auth": {
    "access_token": "ya29...",
    "refresh_token": "1//...",
    "client_id": "...",
    "client_secret": "..."
  }
}
```
Якщо токен оновлюється клієнтом або переданий через конфігурацію, `GoogleDriveExporter` використовує його для авторизованих HTTP-запитів до Google Drive v3 API.
