# F11. Графічний інтерфейс

**Статус**: затверджено 2026-09-14 (вимога замовника: «програма має мати інтерфейс: 1) вибір
папок для відстеження з можливістю вибору місця збереження на локальному пристрої; 2) налаштування»).
Реалізовано в Етапі 0.2: `src/WorkFlowSync.App` — `WorkFlowSync.exe` (Avalonia 11.3).

## Мета

Керувати парами папок і налаштуваннями без редагування `config.json` вручну. GUI і консоль
(`wfs.exe`) працюють з **одним і тим самим** `config.json` поруч із програмою.

## Два виконувані файли

| Файл | Призначення |
|------|-------------|
| `WorkFlowSync.exe` | GUI: пари, налаштування, стан; у Етапі 3 — резидентний режим і трей |
| `wfs.exe` | консоль: `sync --once`, `status`, `import-excludes` — для Планувальника і скриптів |

Обидва — self-contained single-file, звичайний користувач (`asInvoker`).

## Вікно

Вертикальні вкладки ліворуч (як у PathShortener): **Папки · Налаштування · Стан**.
Унизу — рядок стану (помилки червоним) і кнопки **Перевірити · Скасувати зміни · Зберегти**
(останні дві активні лише за наявності незбережених змін).

### Вкладка «Папки»

- Список пар: назва; `джерело → дзеркало`; режим лінків; зберігання («365 дн.» / «назавжди»);
  кількість виключень. Порожній список — підказка «Пар ще немає».
- Кнопки: **Додати пару…**, **Редагувати…** (або подвійний клік), **Видалити**,
  **Імпорт із FreeFileSync…** (F9; вибір `.ffs_batch`/`.ffs_gui`, результат у рядку стану).
- Діалог пари:
  - Назва (автопідстановка з останнього сегмента джерела, унікальна: `vrp`, `vrp-2`…);
  - Мережева папка (джерело) — поле + **Огляд…** (системний вибір папки, UNC підтримується);
  - Локальна папка (дзеркало) — поле + **Огляд…**;
  - Лінки в джерелі: Follow / Skip / Recreate (F4);
  - Зберігання: прапорець «лише те, що з'явилося за останні N днів» (F3); знято = назавжди;
  - Виключення: багаторядкове поле, шаблон у рядку (F6).
  - Валідація при OK: назва непорожня й унікальна; обидва шляхи задані; дзеркало не всередині
    джерела і навпаки; не одна й та сама папка.

### Вкладка «Налаштування»

Інтервал перевірки (хв, для `--loop` і завдання Планувальника); **Автоматичний запуск** — два
перемикачі, що діють одразу (не частина `config.json`): «Запускати при вході в Windows…» (ярлик у
Startup → резидентний `wfs sync --loop`) і «Завдання Планувальника…» (`wfs sync --once` за
інтервалом); результат/помилка — у рядку під ними; перемикачі неактивні, якщо поруч немає
`wfs.exe`. Далі: база стану; папка логів; паралельних листингів (1..64); буфер листингу (КБ);
шлях поточного `config.json` (лише читання). Трей — Етап 4.

### Вкладка «Стан» (реалізовано в Етапі 1)

- Зведення з бази стану: останній прохід (час, результат), розмір бази, за кожною парою —
  «дзеркалюється / видалено локально (не повертати) / змінено локально».
- Кнопки **Показати план (нічого не змінює)** = `wfs sync --dry-run`, **Виконати зараз** =
  `wfs sync --once`, **Зупинити** (скасування; стан перерваного проходу не записується).
- Живий лог проходу (останні 3000 рядків, автопрокрутка); той самий текст іде у `logs\wfs-*.log`.
- Запуск використовує **поточні (навіть незбережені)** пари й налаштування з вікна; при помилках
  валідації запуск відхиляється з поясненням.
- Запуск бере той самий міжпроцесний замок, що й `wfs.exe`: якщо саме зараз іде прохід Планувальника
  або резидента — повідомлення «Інший прохід уже виконується», нічого не запускається.

## Поведінка збереження

- Зміни живуть у пам'яті, доки не натиснуто **Зберегти**; запис атомарний (tmp + replace).
- **Перевірити** запускає ту саму валідацію, що й `wfs config validate`.
- **Скасувати зміни** перечитує файл.
- `WorkFlowSync.exe --config <шлях>` відкриває інший конфіг (для тестів).

## Технічні рішення

- Avalonia **11.3.0** (не 12.x — інший API), FluentTheme, тема системи (світла/темна),
  CommunityToolkit.Mvvm. ViewModel-и без типів Avalonia → mапінг у `SyncConfig` покрито тестами.
- Діалоги й вибір папок — у code-behind вікон (`StorageProvider.OpenFolderPickerAsync`).
- Краш-лог: `logs\crash-*.log` поруч з exe (як у Peromat).

## Сценарії приймання

1. Запуск без `config.json` → порожній список, статус «Конфіг ще не створено…»; додавання пари
   і **Зберегти** створює файл, який `wfs config validate` приймає (перевірено тестом round-trip).
2. Дублікат назви пари → діалог не закривається, повідомлення.
3. Дзеркало всередині джерела → відхилено.
4. Вікно відкривається на вкладці «Папки», список рендериться (перевірено скриншотом 2026-09-14).
