# WorkFlowSync — документація продукту

## Призначення

Одностороннє дзеркало «мережева папка → локальна папка в OneDrive» з пам'яттю про історію:
що вже було скопійовано, що користувач видалив або змінив локально, коли об'єкт уперше з'явився
в джерелі. Замінює FreeFileSync + ручний список виключень на 22 тисячі записів.

## Межі системи

```
┌──────────────────┐   лише читання   ┌────────────────────┐   лише запис    ┌──────────────────┐
│ Мережеві папки   │ ───────────────▶ │ WorkFlowSync.exe   │ ──────────────▶ │ Локальне дзеркало│
│ (SMB, змінювані, │                  │ сканер + планувальник│               │ у OneDrive       │
│  лінки, чужі)    │                  │ + база стану (SQLite)│               │ (власне)         │
└──────────────────┘                  └────────────────────┘                 └──────────────────┘
                                                │
                                                ▼
                                        state.db, logs\  (поруч з exe)
```

Актори: **користувач** (звичайний обліковий запис Windows), **Планувальник завдань / автозапуск**
(запускає програму), **OneDrive** (синхронізує ціль у хмару; для нас — звичайна локальна папка).

Наскрізний потік одного проходу:

1. Завантажити конфіг і стан.
2. Для кожної пари: просканувати джерело (паралельно, крізь лінки) і ціль (лише атрибути).
3. Зіставити зі станом → список дій (копіювати / оновити / позначити tombstone / позначити
   local_modified / видалити за ретенцією).
4. Виконати дії (або лише показати при `--dry-run`).
5. Записати стан однією транзакцією, записати лог.
