# Зміни до наступного випуску (v0.3.18)

Тут зібрано завершені зміни, які увійшли у випуск v0.3.18.

## Виправлено

- Виправлено сканування каталогів довших за 260 символів у Windows з `LongPathsEnabled = 0` за допомогою Win32 префікса розширених шляхів (`\\?\`).
- Усунено збої сканування та помилкові масові tombstones на каталогах OneDrive із точками повторної обробки.
- Скорочення папок зроблено повністю детермінованим (не залежить від довжини імені чи розширення файлу), що запобігає розкиданню файлів однієї папки по різних варіантах.
- Реалізовано відновлення (revive) помилкових Tombstones у `state.db` до статусу `Active` під час виконання `repair`.
- Додано автоматичне очищення у Кошик порожніх папок-варіантів та конфліктних копій хмарних клієнтів (виду `... (1).pdf`).
- У режимі `repair_required` заблоковано виконання `CopyFile` для вже відстежуваних файлів.
- Виправлено зняття блокування `repair_required` після успішного планування та виправлення цілі.
- Усунено помилку `Cannot fit directory within path limit` для глибоких каталогів завдяки динамічному бюджетуванню довжини.
