# Changes for the Next Release

Keep only completed, user-visible changes since the previous release. Adapt headings and entries to
the product's user-facing language. Do not include implementation details, code symbols, file names,
commits, or agent attribution.

## Fixed

- На слабких комп'ютерах перевірка папок займала весь процесор, і вікно програми переходило
  в стан «не відповідає». Тепер прохід виконується зі зниженим пріоритетом і меншою кількістю
  паралельних читань, а живий журнал у вікні оновлюється не частіше ніж кілька разів на секунду.

- Автозапуск у режимі «зі значком в області сповіщень» показував вікно програми під час
  завантаження Windows. Тепер програма стартує тихо: лише значок біля годинника.

- Перемикачі автозапуску були недоступні, якщо поруч із програмою немає консольного файла,
  хоча для варіанту «в області сповіщень» він не потрібен.

## Changed

- У картці пари замість трьох окремих кнопок — меню ⋯ («Перевірити зараз», «Редагувати…»,
  «Видалити»).
- Лічильники в налаштуваннях і діалозі пари перемальовані: кути кнопок більше не обрізаються.
- Блок «Файли програми» вирівняно за шириною з рештою; у ньому лише папка програми та строк
  зберігання журналів.

- Сторінка «Синхронізація» спрощена до кнопки «Синхронізувати» та історії; історія
  переноситься по рядках без горизонтальної прокрутки.
- Нові іконки меню та кнопок (єдиний набір), тонкі смуги прокрутки у власній смузі, скруглені
  кнопки лічильників.
- Зміни налаштувань і пар зберігаються автоматично — кнопки «Зберегти», «Скасувати зміни» і
  «Перевірити» прибрано; рядок повідомлення внизу з'являється лише за потреби.
- Лічильники й випадні списки приведено до спільного стилю; вміст сторінок доходить до смуги
  прокрутки без широкого порожнього краю.

## Added

- Налаштування «Навантаження на процесор» («Налаштування» → «Продуктивність сканера»):
  помірне (типово), повне або низьке — для слабких комп'ютерів.

- Тип синхронізації для кожної пари: «Дзеркало (в один бік)» — як раніше, або «Повна синхронізація
  (в обидва боки)», де створення, зміни й видалення переносяться в обидві папки, а видалене
  потрапляє в Кошик. Тип обирається в налаштуваннях пари, а в картці пари між двома шляхами
  показано значок: одна стрілка для дзеркала, подвійна — для повної синхронізації.
- Пара, у якої обидві папки — та сама, або одна лежить усередині іншої, більше не приймається:
  такий запис відхиляється і у вікні пари, і у вручну відредагованому файлі налаштувань.

- Строк зберігання журналів («Налаштування → Файли програми → Зберігати журнали», 1–3650 днів,
  типово 30): старіші файли видаляються автоматично при наступному проході.

- Усі файли програми (config.json, база стану, журнали) зберігаються в папці, з якої її запущено;
  конфігурація створюється там одразу при першому запуску. У «Налаштуваннях» показано папку
  програми з кнопкою «Відкрити» і повні шляхи бази й журналів.
- Новий вигляд програми: світла й темна теми (перемикач у «Налаштуваннях», за замовчуванням —
  як у Windows), навігація ліворуч замість вкладок, сторінки «Папки», «Синхронізація» й
  «Налаштування», картки з чіткою ієрархією, власні іконки.
- Пару можна редагувати й видаляти прямо з її рядка (видалення — з підтвердженням).
- Інтерфейс очищено від зайвого: без підзаголовків, індикаторів і службових написів; імпорт із
  FreeFileSync — у «Налаштуваннях».
- У кожного рядка пари з'явилася одна кнопка **▶/⏸** і кружечок стану: зелений — пара
  перевіряється автоматично із заданим інтервалом, сірий — на паузі. Натискання діє одразу:
  щойно запущена пара перевіряється негайно, далі — за інтервалом. Поруч є кнопка
  **Перевірити зараз** для одноразової синхронізації однієї пари.
- Автоматична перевірка більше не потребує окремого вмикача: працюють ті пари, що позначені ▶.
  Стан пар запам'ятовується, тож після перезапуску програма продовжує перевіряти сама.
- Значок в області сповіщень: програма може працювати біля годинника й сама перевіряти папки.
  Меню значка — стан, «Відкрити вікно», «Синхронізувати зараз», пауза/запуск фонового режиму, «Вийти».
  Закриття вікна ховає програму в область сповіщень (вихід — через меню значка).
- Автозапуск при вході в Windows тепер на вибір: зі значком в області сповіщень або фоновим
  процесом без вікна.
- Власна іконка програми.
- Резидентний режим: програма може працювати у фоні й перевіряти мережеві папки за заданим
  інтервалом; зміни налаштувань підхоплюються без перезапуску.
- Автоматичний запуск без прав адміністратора — два перемикачі в «Налаштуваннях» (і команди
  `wfs autostart`, `wfs task`): запуск при вході в Windows або завдання Планувальника.
- Одночасно виконується лише один прохід для конфігурації, хоч звідки його запущено (вікно,
  Планувальник, фоновий режим).
- Логи старші за 30 днів видаляються автоматично.
- Термін зберігання: для пари можна задати «зберігати лише те, що з'явилося за останні N днів» —
  старіші файли переносяться в Кошик і більше не повертаються; папки, що спорожніли, теж
  прибираються в Кошик, але повернуться, щойно в них з'явиться щось нове. Файли, змінені
  локально, термін не зачіпає.
- Імпорт із FreeFileSync (кнопка на вкладці «Папки» або `wfs import-excludes`): список виключень
  переноситься як шаблони і як позначки «не повертати», тож перехід не повертає жодного раніше
  видаленого файлу.
- `wfs forget <шлях>` — забути позначку, щоб об'єкт знову скопіювався як новий.
- Синхронізація працює: нові папки й файли з мережевої папки копіюються в локальне дзеркало,
  оновлені в джерелі файли оновлюються, якщо локальну копію не чіпали; видалене в джерелі
  лишається локально; видалене, переміщене або змінене локально більше ніколи не повертається
  з джерела (у т.ч. нові файли в локально видаленій папці).
- Дата появи кожного об'єкта фіксується в момент, коли програма вперше побачила його в джерелі;
  для вже наявних на першому запуску файлів береться найраніша з дат створення/зміни.
- Лінки (junction/symlink) у джерелі проходяться і копіюються як звичайні папки; лінки, що ведуть
  «назад» (цикли), пропускаються з попередженням.
- Приховані та системні файли дзеркалюються.
- Недоступна мережева папка не вважається «порожньою»: пара пропускається, нічого не змінюється.
- Консоль: `wfs sync` (з `--dry-run` для перегляду плану без змін), `wfs status`; захист від
  одночасних запусків.
- Вкладка «Стан»: зведення за парами, «Показати план», «Виконати зараз», «Зупинити», живий лог.
- Графічний інтерфейс `WorkFlowSync.exe`: вкладка «Папки» — додавання, редагування й видалення пар
  «мережева папка → локальна папка» з вибором папок через системний діалог, режим лінків,
  термін зберігання і виключення; вкладка «Налаштування» — інтервал перевірки, база стану, папка
  логів, параметри сканера; перевірка й збереження конфігурації.
- Консольна утиліта `wfs.exe` з командами `config validate` і `version`; при запуску подвійним
  кліком вікно не закривається саме.
