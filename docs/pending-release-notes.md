## Added

- У параметрах системи завдання з’явилися три окремі опції: незалежний захист резерву місця на
  диску, автоматичне вивантаження нових копій у OneDrive/Files On-Demand та ротація найстаріших
  копій у будь-якій кінцевій теці.
- Ротація остаточно видаляє без Кошика лише незмінені файли, які скопіювала програма. Вона доступна
  також у хмарній теці, де провайдер може синхронізувати видалення з хмарою. Джерело залишається недоторканим.
- Сумісні хмарні теки визначаються автоматично; окремий токен або права адміністратора не потрібні.
- Спрощено відображення дискової квоти в інтерфейсі завдання: прибрано заголовок «захищати вільне місце на диску», а після чекбоксу відразу відображається текст «залишати вільними» та поле для введення кількості ГБ.
